# magnavox-1084-feet
3D printable feet for the Commodore 1084 and the Philips/Magnavox variants.

Got a Magnavox or Commodore 1084 variant with those worn down or missing rubber feet?

Curved bottom feet, great for printing out with ABS, PLA, TPU, or Siraya Tenacious resin.

Or flat bottom feet if you already have a favourite rubber bumper you’d like to attach.

Proudly created using OpenSCAD. No AI (though AI probably could have done a better job).

Updated. added indent so that rubber feet can be inserted into the foot, hopefully preventing the glued on rubber feet from sliding around.
