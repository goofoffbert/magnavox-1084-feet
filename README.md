# magnavox-1084-feet
3D printable feet for the Commodore 1084 and the Philips/Magnavox variants.

Got a Magnavox or Commodore 1084 variant with those worn down or missing rubber feet?

<b>Curved bottom feet</b>, great for printing out with ABS, PLA, TPU, or Siraya Tenacious resin.

Or <b>flat bottom feet</b> which has an insert that will fit a 12.7mm (1/2") diameter bumper.

Proudly created using OpenSCAD. No AI (though AI probably could have done a better job).
